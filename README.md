## Pregunta de investigación
¿De qué manera la gestión institucional, el área geográfica y el sexo del estudiante influyen en los puntajes de lectura y matemática en la ENLA 2024?

## Datos
- **Fuente:** Ministerio de Educación del Perú (MINEDU) - ENLA 2024 (6.° grado de primaria).
- **Licencia:** Datos Abiertos del Estado Peruano.

## Cómo reproducir
1. Clona o descarga este repositorio.
2. Abre el proyecto haciendo doble clic en el archivo `.Rproj`.
3. Ejecuta `renv::restore()` en la consola de R para instalar las versiones exactas de los paquetes.
4. Renderiza los documentos Quarto ubicados en la carpeta `analysis/`.
